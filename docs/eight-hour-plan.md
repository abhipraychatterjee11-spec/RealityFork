# Eight-hour hackathon plan

## Prepare before the event

- Install Node.js, pnpm, Docker and a browser wallet.
- Create the repository and verify that every teammate can run it.
- Prepare two road-condition photographs with permission to use them.
- Create test wallets and fund them on the selected testnet.
- Decide the exact Road A17 claim schema and demo wording.
- Keep fallback screenshots and a recorded transaction explorer view.

## Build during the event

| Time | Deliverable | Owner suggestion |
|---|---|---|
| 0:00–1:00 | Shared schema, sample evidence and API health route | Backend lead |
| 1:00–2:30 | Create commit, fork and history endpoints | Backend lead |
| 1:00–3:00 | Dashboard, claim cards and Reality Diff | Frontend lead |
| 2:00–4:00 | Compile and deploy RealityRegistry | Web3 lead |
| 3:00–5:00 | Evidence upload stub, hashing and scoring | Backend plus Web3 |
| 5:00–6:00 | Challenge and merge happy path | Whole team |
| 6:00–7:00 | Integration, error handling and demo data | Whole team |
| 7:00–8:00 | Rehearsal, screenshots and final submission | Presenter plus team |

## Cut first if time runs short

- Live AI media detection: use a recorded risk score and explain the production path.
- Full PostgreSQL adapter: keep the in-memory store for the live demo.
- Wallet signatures for every role: use one relayer and show signer addresses.
- Map interactions: show a fixed Road A17 location.
